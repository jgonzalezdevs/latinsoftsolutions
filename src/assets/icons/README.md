# Iconos necesarios para SEO y PWA

Genera los siguientes iconos a partir de tu logo:

## Iconos PWA (requeridos)
- `icon-72x72.png`
- `icon-96x96.png`
- `icon-128x128.png`
- `icon-144x144.png`
- `icon-152x152.png`
- `icon-192x192.png`
- `icon-384x384.png`
- `icon-512x512.png`

## Favicons (requeridos)
- `apple-touch-icon.png` (180x180)
- `favicon-32x32.png`
- `favicon-16x16.png`
- `safari-pinned-tab.svg`

## Iconos para shortcuts (opcionales)
- `contact-icon.png` (96x96)
- `projects-icon.png` (96x96)

## Herramientas recomendadas
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator
- https://favicon.io/

## Imagen Open Graph
Crear en `src/assets/`:
- `og-image.png` (1200x630) - Imagen para compartir en redes sociales
- `logo.png` - Logo de la empresa

## Screenshots para PWA (opcionales)
Crear en `src/assets/screenshots/`:
- `desktop.png` (1920x1080)
- `mobile.png` (390x844)
